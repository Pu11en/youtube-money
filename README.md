# youtube-money

Faceless YouTube videos made from a Discord thread with Claude/Codex + Blotato.
Start with `AGENTS.md`; the proven prompt kit is in `research/style-cloner-sources/SUMMARY.md`.

## About the prompt kit
`research/style-cloner-sources/prompts/` holds only MIT-licensed excerpts and short,
attributed quotes. Full copies of prompts that have no open license (Blotato, n8n,
Reddit and some GitHub sources) are kept private; each is linked with its author in
`github.md`, `n8n.md` and `community.md` so you can read the original.
