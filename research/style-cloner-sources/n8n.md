# n8n / Make / Blotato template sources for the style cloner

Researched 2026-09-18. Method: queried the public n8n template API (`api.n8n.io/api/templates/search`) for 30+ terms (youtube script, faceless, viral, clone, rewrite, transcript, storytelling, shorts, reels, hook, narration, blotato, heygen, retention, brand voice, writing style, competitor youtube, and more). That gave about 400 unique templates. I pulled the full workflow JSON for the 67 most relevant (`/api/templates/workflows/<id>`) and extracted every LLM prompt. I also pulled Blotato's own template JSON (from the Google Drive folder its help page links to), Blotato's help-center prompts, and Blotato's public Claude skills repo. Make.com: its gallery is rendered in the browser and blueprints need a login, so I couldn't search it properly. The only Make blueprints I could read were Blotato's 7.1/7.2, and they contain the same prompt as the n8n version.

View counts are n8n's `totalViews` as of today. n8n no longer exposes usage/insert counts.

## Worth knowing, not saved

- **The top templates by views have nothing useful for scripts.** 5338 (342k views) and 5035 (278k), both Dr Firas, only write Veo/Seedance visual prompts (ASMR slicing, selfie vlogs). 3654 (29k) writes two 50-character overlay lines.
- **Visual cloning, not script cloning:** 6104 (Lucas Walter, "Digital Twin Architect", Gemini watches the video shot by shot) and 2993 (copy viral reels). Good forensic-analysis prompt style, wrong layer for us.
- **Persona "series bible":** 5312 (Bigfoot vlog, Lucas Walter, 5.3k) locks a character's voice and look across 8 scenes. Relevant only if we give the narrator a persona.
- **Some templates come back with their prompts blanked out:** 4650 "Clone LinkedIn writing styles … prompt generation" (b4dr), 2941 YouTube Shorts tool (Jonas Busch, 22k), 2875 faceless YouTube agent (Simon Scrapes), 3553, 2971, 4107, 15145. Their parameters are empty `{}` on every n8n API endpoint, and GitHub mirror searches found nothing. 4650 would have been the most on-target (analyze style → generate a reusable style prompt). 6014 is an unblanked copy of 2875's "60 Second Script Writer", and it's generic ("use CAPITAL LETTERS generously").
- **Blotato's in-app prompts** "Youtube Video Script", "Youtube Description and Timestamps" and "Template From Existing Post" exist ([help](https://help.blotato.com/tips-and-tricks/youtube-scripts)), but their text is only visible inside a logged-in Blotato account. Worth reading from Drew's account; it costs nothing to look.

## Verdict

n8n templates are almost all **generic** for our purpose. They're short-form (30–60 s), they copy style from a single transcript with no analysis step, and none of them produce an explicit style-DNA object, handle long-form retention (open loops, mid-video re-hooks, reveal timing), or grade a script for retention. View counts favor video-generation spectacle, not good writing. The good news is that a few pieces combine cleanly:

- **Extract (#4 + #6 + #7):** a structure description plus voice traits with quoted examples, extended with hook_type/promise labels.
- **Write (#1/#2 rules + #5 reference-script slot + #3's style of BAD/GOOD examples):** "keep X, may change Y" lists, the same level of specificity, the same type of content.
- **Grade (#8 + #9):** a weighted rubric with a harsh default and quote → why → fix output, which needs new retention dimensions for long-form.

Everything worth using is prompt text. We can rerun all of it on Claude and skip the paid add-ons.
