# YouTube reference library

Links David and Drew find that we may want to learn from later: channels, videos, Shorts.
Storage only. Nothing is downloaded or transcribed until a session is asked to.

## How to add
- Paste links in Discord and say "add to the library". The session appends a row to
  `found-by-david.md` (or a new `found-by-<name>.md`): date, link, what it is, one-line note.
- Keep the note in the finder's own words. Don't rewrite it.
- Same link twice: keep the first row, add the new note to it.

## How to use
- "What's in the library?" → the session reads the tables and lists them.
- "Pull the transcript / style DNA for X" → the session fetches it then and saves it under
  `research/private-transcripts/` (git-ignored).
